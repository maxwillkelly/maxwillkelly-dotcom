# How I work

I use AI coding agents to write, review and test code. I use both [Anthropic](https://www.anthropic.com/) and [OpenAI](https://openai.com/) models regularly through harnesses such as [Claude Code](https://claude.com/product/claude-code), [Codex](https://chatgpt.com/codex/) and [OpenCode](https://opencode.ai/).

I take complete ownership of all the code I ship, including code written by AI, and make sure I understand how it works and can explain and justify its design decisions.

I write and maintain code that other developers can easily read and understand, with clear naming, thoughtful organisation, and abstractions with an obvious purpose.
